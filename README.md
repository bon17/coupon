# 🎟️ 쿠폰 출력기

학생 이름·쿠폰 이름·사용기간이 들어간 학급 보상 쿠폰을 A4에 6장씩 컬러로 출력하는 웹 앱이에요.
설치 없이 `index.html` 파일 하나만 크롬·웨일·엣지에서 열면 돼요.

## 여는 방법
1. [index.html 페이지](https://github.com/bon17/coupon/blob/claude/admiring-curie-l1y6u2/index.html)에서 오른쪽 위 **다운로드(Download raw file)** 버튼을 눌러요.
2. 받은 `index.html`을 더블클릭해서 크롬·웨일·엣지로 열어요.
3. 입력한 명단·쿠폰·설정은 그 컴퓨터의 브라우저에 자동 저장돼요. 다른 컴퓨터에서 쓰려면 **설정·백업 → 백업 파일 저장**으로 옮겨요.

> 글꼴은 인터넷(Google Fonts)에서 불러와요. 인터넷이 안 되면 맑은 고딕으로 나와요.

## 사용 순서
1. **학생 명단**: 엑셀에서 번호·이름 두 칸을 복사해서 붙여넣기 → *이 명단으로 바꾸기*
2. **쿠폰 관리**: 공통 문구(윗줄 문구·해시태그·발행인·확인칸·안내 문구), 제목 글꼴, 선생님 확인 도장, 쿠폰별 이름·색·그림·규칙 문구를 정해요.
3. **발급·인쇄**
   1. 쿠폰을 골라요. 간식 교환권이면 간식과 쿠폰 디자인도 골라요.
   2. 학생을 체크해요. 이름 빈칸 쿠폰도 만들 수 있어요.
   3. 사용기간을 정해요. 기한 없음도 가능해요.
   4. 필요하면 주의사항을 적어요.
   5. **출력 목록에 담기**를 눌러요. 다른 쿠폰끼리 섞어서 담아도 한 장에 6개씩 채워져요.
4. **인쇄하기**: 쿠폰 뒤에 **발급 내역**(일련번호·이름·쿠폰·사용기간·사용 확인칸)도 함께 나와요. 끌 수도 있어요.

## 인쇄 설정
- 용지 **A4**, 방향 **세로**
- 배율 **기본값(100%)**: '페이지에 맞춤'은 끄기
- 여백 **기본값** 또는 **없음**
- 색이 안 나오면 **배경 그래픽** 체크
- 칸 경계의 점선을 따라 자르면 한 번에 양쪽 쿠폰이 잘려요. 한 칸은 9.2cm 정사각형이에요.

## 복사 방지
- **일련번호**: 날짜별로 계속 올라가요(예: `261025-007`). 발급 내역에서 이미 사용 확인된 번호가 또 나오면 복사본이에요.
- **일련번호 바코드**: 쿠폰마다 무늬가 달라요(장식용).
- **확인 도장칸**: 도장 이미지를 넣으면 쿠폰마다 다른 각도로 찍혀요. 비워 두면 직접 도장을 찍을 수 있어요.
- **마이크로 문자**: 아주 작은 글씨 줄이라 복사하면 뭉개져요.

## 그림 넣기
- 쿠폰 관리에서 쿠폰(또는 간식)마다 **이미지 올리기**를 누르면 돼요. 흰 배경은 자동으로 지워지고 여백도 잘라져요.
- 각 쿠폰의 **🎨 프롬프트** 버튼으로 ChatGPT 그림 프롬프트를 복사할 수 있어요. 새 간식은 이름만 적으면 프롬프트가 만들어져요.
- 기본 그림은 [`images/`](images/) 폴더에 있어요. 그림을 추가하거나 바꾼 뒤 `python3 tools/embed_images.py`를 실행하면 `index.html` 안에 들어가요(파일 이름 = 그림 키, `images/README.md` 참고).

### 그림 프롬프트 공통 스타일
```
스타일: 귀엽고 깔끔한 3D 아이콘 일러스트, 말랑한 클레이 질감, 밝은 파스텔 톤, 부드러운 조명과 그림자, 살짝 위에서 본 시점. 물체만 화면 중앙에 크게. 글자·숫자·로고 없음. 배경은 투명한 PNG, 정사각형.
```

|---|---|---|
| 청소 면제권 | 파란색 밀대 걸레와 분무기, 주변에 몽글몽글한 비눗방울 | 하늘색·파란색 |
| 자리 우선권 | 작은 금색 왕관이 올려진 빨간색 교실 의자 | 빨간색·금색 |

| 간식창고 털이권 | 뚜껑이 열린 나무 보물상자에 과자·사탕·초콜릿이 가득 넘치는 모습 | 주황색·갈색 |

| 사탕 | 양 끝을 리본처럼 비튼 포장지에 싸인 알록달록한 사탕 여러 개 | 분홍·노랑·주황 |

| 직접 입력한 간식 | 과자·젤리·사탕이 알록달록 섞여 담긴 귀여운 간식 봉지 | 노랑·주황 |
| 꽝 | 뚜껑 열린 빈 선물상자에서 용수철 달린 얼굴이 튀어나와 메롱 하는 모습 | 회색 + 노랑·하늘색 |

**선생님 확인 도장**: 쿠폰 관리 → *🎨 도장 프롬프트 복사*를 누르면 발행인 이름으로 된 도장 프롬프트가 복사돼요(예: 「보은쌤인」).
