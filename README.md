# 🎟️ 쿠폰 출력기

학생 이름·쿠폰 이름·사용기간이 들어간 학급 보상 쿠폰을 A4에 6장씩 컬러로 출력하는 웹 앱이에요.
설치 없이 `index.html` 파일 하나만 크롬·웨일·엣지에서 열면 돼요.

## 여는 방법
1. [index.html 페이지](index.html)에서 오른쪽 위 **다운로드(Download raw file)** 버튼을 눌러요.
2. 받은 `index.html`을 더블클릭해서 크롬·웨일·엣지로 열어요.
3. 입력한 명단·쿠폰·설정은 그 컴퓨터의 브라우저에 자동 저장돼요. 다른 컴퓨터에서 쓰려면 **설정·백업 → 백업 파일 저장**으로 옮겨요.

> 기본 글꼴인 **나눔스퀘어라운드**는 앱 안에 들어 있어서 인터넷 없이도 나와요. 다른 글꼴(주아·도현·나눔손글씨 등)은 인터넷(Google Fonts)이 필요하고, 인터넷이 안 되면 기본 글꼴로 나와요.

## 사용 순서
앱을 열면 **① 쿠폰 만들기**부터 시작해요.
1. **① 쿠폰 만들기**
   - 공통 문구(윗줄 문구·해시태그·발행인·확인칸·안내 문구), 선생님 확인 도장을 정해요.
   - **제목 글꼴**(TO. 이름·쿠폰 이름·사용기간)과 **내용 글꼴**(윗줄 문구·해시태그·사용 방법)을 따로 골라요.
   - 쿠폰마다 이름·색·그림·**사용 방법**을 정한 뒤 **이 쿠폰 발급하러 가기 →**를 누르면 그 쿠폰이 골라진 채로 발급 화면으로 넘어가요.
2. **② 학생 명단**: 엑셀에서 번호·이름 두 칸을 복사해서 붙여넣기 → *이 명단으로 바꾸기*
3. **③ 발급·인쇄**
   1. 쿠폰을 골라요. 간식 교환권이면 간식과 쿠폰 디자인도 골라요.
   2. 학생을 체크해요. 이름 빈칸 쿠폰도 만들 수 있어요.
   3. 사용기간을 정해요. 기한 없음도 가능해요. 자주 쓰는 날짜는 **＋ 지금 날짜 저장**을 누르면 📌로 남아서 다음에도 한 번에 고를 수 있어요.
   4. 필요하면 주의사항을 적어요.
   5. **출력 목록에 담기**를 눌러요. 다른 쿠폰끼리 섞어서 담아도 한 장에 6개씩 채워져요.
4. **인쇄하기**: 쿠폰 뒤에 **발급 내역**(일련번호·이름·쿠폰·사용기간·사용 확인칸)도 함께 나와요. 끌 수도 있어요.

## 🎁 간식 뽑기
학생이 직접 이름을 적고 **간식 뽑기!** 버튼을 누르면 카드 하나가 뽑히고, 그 간식의 교환권이 바로 **출력 목록**에 담겨요.
- 뽑기 카드는 **간식 교환권**의 간식 목록과 **꽝**이에요. 오른쪽 **선생님 설정**에서 이번 뽑기에 넣을 카드만 켜고 끌 수 있어요.
- 기본 간식은 마이쮸·사탕·초콜릿·젤리·과자·음료수·비타민이에요. **＋ 간식 추가**에 이름을 적으면 바로 늘릴 수 있고, 그림과 색은 *간식 그림·디자인 고치기 →*에서 바꿔요.
- 간식끼리는 **모두 같은 확률**이에요. **꽝**은 간식 하나보다 조금 더 자주 나와요(기본 **1.2배**: 간식이 50이면 꽝은 60). *똑같이·1.2배·1.5배·2배* 중에서 고를 수 있고, 카드마다 실제 확률(%)이 적혀 있어요.
- 뽑을 때마다 새로 뽑아서 **같은 간식이 또 나올 수 있어요**(같은 학생이 두 번 뽑아도, 다른 학생이 뽑아도). 브라우저의 암호용 난수로 뽑아서 치우침이 없어요.
- **한 사람당 뽑기 횟수**를 정할 수 있어요(1~20번, 또는 *제한 없음*). 남은 횟수가 있으면 결과 화면에 **한 번 더 뽑기** 버튼이 나와요. 명단에 없는 이름을 적으면 한 번 더 물어봐요.
- 꽝이 나오면 **꽝 쿠폰**도 출력 목록에 담겨요. *꽝 쿠폰도 출력 목록에 담기*를 끄면 화면에만 나오고 출력하지 않아요.
- 사용기간·주의사항은 **③ 발급·인쇄**에서 정한 값이 그대로 들어가요.
- **뽑기 기록**에서 누가 무엇을 뽑았는지, 간식별로 몇 개 나갔는지 보여요. 이름을 잘못 적었으면 ✕를 누르면 출력 목록에서도 빠져요. 다음 뽑기 때는 *기록 지우고 새로 시작*을 눌러요.
- 다 뽑은 뒤 **인쇄하기**를 누르면 뽑힌 쿠폰들이 한꺼번에 출력돼요.

## 인쇄 설정
- 용지 **A4**, 방향 **세로**
- 배율 **기본값(100%)**: '페이지에 맞춤'은 끄기
- 여백 **기본값** 또는 **없음**
- 색이 안 나오면 **배경 그래픽** 체크
- 칸 경계의 점선을 따라 자르면 한 번에 양쪽 쿠폰이 잘려요. 한 칸은 9.2cm 정사각형이에요.

## 복사 방지
- **일련번호**: 날짜별로 계속 올라가요(예: `261025-007`). 발급 내역에서 이미 사용 확인된 번호가 또 나오면 복사본이에요.
- **일련번호 바코드**: 쿠폰마다 무늬가 달라요(장식용).
- **선생님 확인 칸**: 도장 이미지를 넣으면 확인 칸 안에 쿠폰마다 살짝 다른 각도로 찍혀요. 비워 두면 빈칸이라 직접 도장을 찍을 수 있어요.

## 그림 넣기
- 쿠폰 만들기에서 쿠폰(또는 간식)마다 **이미지 올리기**를 누르면 돼요. 흰 배경은 자동으로 지워지고 여백도 잘라져요.
- 각 쿠폰의 **🎨 프롬프트** 버튼으로 ChatGPT 그림 프롬프트를 복사할 수 있어요. 새 간식은 이름만 적으면 프롬프트가 만들어져요.
- 기본 그림은 [`images/`](images/) 폴더에 있어요. 그림을 추가하거나 바꾼 뒤 `python3 tools/embed_images.py`를 실행하면 `index.html` 안에 들어가요(파일 이름 = 그림 키, `images/README.md` 참고).

### 그림 프롬프트 공통 스타일
```
스타일: 귀엽고 깔끔한 3D 아이콘 일러스트, 말랑한 클레이 질감, 밝은 파스텔 톤, 부드러운 조명과 그림자, 살짝 위에서 본 시점. 물체만 화면 중앙에 크게. 글자·숫자·로고 없음. 배경은 투명한 PNG, 정사각형.
```

**선생님 확인 도장**: 쿠폰 만들기 → *🎨 도장 프롬프트 복사*를 누르면 발행인 이름으로 된 도장 프롬프트가 복사돼요(예: 「보은쌤인」).

## 글꼴 라이선스
앱 안에 들어 있는 나눔스퀘어라운드는 네이버 나눔글꼴로, SIL 오픈 폰트 라이선스(OFL 1.1)를 따라요([`fonts/OFL.txt`](fonts/OFL.txt)). 글꼴 파일을 바꾼 뒤 `python3 tools/embed_fonts.py`를 실행하면 `index.html` 안에 들어가요.
