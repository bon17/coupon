# 쿠폰 그림 올리는 곳

ChatGPT로 만든 쿠폰 그림을 이 폴더에 올려 주세요. 파일 이름은 아무거나 괜찮아요(앱에 넣을 때 아래 이름으로 바꿔요).

| 그림 | 들어가는 쿠폰 | 파일 이름 |
|---|---|---|
| 밀대 걸레·분무기 | 청소 면제권 | `c-clean` |
| 왕관 올린 의자 | 자리 우선권 | `c-seat` |
| 건너뛰기 버튼·말풍선 | 잔소리 스킵권 | `c-nag` |
| 간식 보물상자 | 간식창고 털이권 | `c-stash` |
| 네모난 츄잉 캔디 | 간식 교환권 – 마이쮸 | `snack-mychew` |
| 비튼 포장 사탕 | 간식 교환권 – 사탕 | `snack-candy` ✅ |
| 판 초콜릿 | 간식 교환권 – 초콜릿 | `snack-choco` |
| 간식 봉지 | 간식 교환권 – 직접 입력한 간식 | `snack-custom` |
| 메롱 깜짝 상자 | 꽝 | `c-miss` |
| 보은쌤인 도장 | 선생님 확인칸 | `stamp` |

그림을 바꾼 뒤 `python3 tools/embed_images.py`를 실행하면 `index.html` 안에 들어가요.
